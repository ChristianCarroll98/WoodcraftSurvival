How this file is used
- Tasks here track actual work steps derived from Roadmap.txt and the system implementation docs.
- When a task is added, removed, split, or marked done in this file, say so in chat so the GitHub board can stay in sync. Do not silently drop a card that still exists on GitHub, and do not open a GitHub card that is not listed here first (or add it here in the same pass).
- Status: Backlog, In Progress, Done.
- Size: XS = 1 day, S = 2-3 days, M = 4-7 days, L = 8-14 days, XL = 15+ days.
- Labels: art-assets, blocked, bug, documentation, feature, polish, tech-debt, ui.
- Blocking = cards this task holds up. Blocked By = cards / work that must land first. Empty is OK.
- Order below is do-first to do-last for the current milestone slice.

ORM Texture note:
In Unreal Engine 5.8, ORM textures must have sRGB disabled and compression set to "Masks" to ensure Occlusion, Roughness, and Metalness channels are treated as linear math data rather than color, preventing visual distortions [1]. For C++ projects, this is achieved by setting SRGB = false and CompressionSettings = TC_Masks on the UTexture2D object to avoid improper gamma correction on packed data [1]. You can read more about texture optimization in Unreal Engine's official documentation. [1, 2, 3] 
[1] [https://github.com](https://github.com/EmbarrassingMoment/RGBPackingTool)
[2] [https://www.youtube.com](https://www.youtube.com/watch?v=9GgZRO4Uxso)
[3] [https://dev.epicgames.com](https://dev.epicgames.com/community/learning/knowledge-base/a3vO/unreal-engine-why-is-my-texture-streaming-pool-giving-me-a-warning)

Architecture reminder:
- Fragments = data + minimal spawn/init hooks. No runtime work in fragments.
- Actors stay thin. Behaviour lives in systems.
- Same resistance shape will be reused on Creatures/Player later.
- MVP first — no composite tools, no part durability until much later.
- Physical Materials = single source of truth for density/mass + future impact/softness scales.
- Dual-mesh tools: fixed Physics Constraint (not WeldTo). SecondaryRelativeTransform must be correct on the Item Definition.
- Named primitives on Static Meshes drive candidate DamageType (multiple author names can map to one type). Incidence can demote Slash/Pierce → Blunt.
- EItemStrikeMode on EquippableItemFragment drives both incidence axes and procedural orientation.
- Per-hand state lives in FHandState on HeldItemsComponent (including LastItemVelocity for pre-bounce incidence + orientation).
- Procedural orientation writes only TargetOrientation on the existing Physics Control (position stays skeletal + linear). Grip transform / arm IK continues to follow the live item.
- Q-mode suppresses swing / procedural orient / collision damage. Place-on-socket is Q-hold preview + release commit; stacks never leave the hand except as a world drop.
- Socket preview snap uses a shared ReleasePose + loose location-only IK (no grip rotation) so the FP wrist is not twisted to the socket.

Woodcraft Survival – Project Roadmap
(Created 2026-08-26. Living document. High level only.)

Purpose
- This file is the high-level sequence of milestones. Look here when a task finishes and you need to choose the next slice.
- System implementation docs (ItemSystem/, HarvestableSystem/, CraftingSystem/, later StructureSystem/, CreatureSystem/) own locked architecture and small tasks for that system.
- Notes/Tasks.txt owns the current working task cards. ProjectNotes.txt points there and keeps architecture reminders. Do not delete DONE lines from ProjectNotes without confirmation.

Core loop
Find loose resources → hold and swing a physical tool → harvest a standing resource into items → combine items into a better tool (hands, then a station) → harvest something the previous tool could not → repeat.

Food, fire, shelter, creatures, seasons, and the guidebook press on that loop. They are not the loop itself.

Current milestone: Core Loop Playable
A short session that starts nearly empty and completes gather → first ground craft → harvest → station craft → better harvest, using the live physics swing / incidence / orientation path.

Art rule for this milestone
Readable color + authored ORM as assets are painted (pipeline locked: sRGB off, Masks). Shared Wood / Stone / Plant Physical Materials. Correct scale, named collision primitives, Neutral + Extended HoldPoses per item. Faceted Edge normals. Assembled hatchet may reuse `SM_SharpenedStone` with a second ORM / MI for wrap contact.

Locked decisions (2026-08-26)
- Hold is HoldPose + item origin + dynamic grip (AnimRef Hand relative to WeaponBone × item world transform). Left-hand mesh scale X=-1 still applies.
- Station / placement sockets: Workbench has one slot socket.
- PlacementOffsetTransform lives on UItemDefinition (default Identity). Every station socket uses the same frame: origin on the surface, +Z up, +X forward. The item actor is placed at SocketTransform × PlacementOffsetTransform. Per-station special offsets: later if needed.
- Place onto a socket: Q + mouse hold extends the item (preview-snap, commit on RELEASE). Retrieve from a socket uses the same pickup path as a ground item. Held stacks: Q + mouse release drops the whole stack.
- Cordage, Plant Fiber, Fibrous Stalk: Equippable, StrikeMode None. Fiber-source tag on the stalk.
- Stick: Equippable, StrikeMode None, Damage fragment, blunt swing.
- Stone: Equippable, StrikeMode SingleEdged, Damage fragment, Blunt primitives (orient a flat; hits stay blunt).
- StoneHatchet Primary mesh is StickHandle (static mesh only). Secondary is welded to Primary (`WeldTo`). Optional material overrides on the Definition.
- Recipes list allowed crafting locations (Hands / Ground and station ids). Station fragments carry a station id. Detection uses looked-at station or the item already in its slot. Recipe assets own the recipe list.
- Fragments stay data + spawn/init hooks on Structures, same as Items and Harvestables.
- Sharpened stone can cut trees and the fibrous plant. Stone hatchet is gated on the workbench.

Slices (do in order; each should be playable before the next starts)

A1. T1 content — DONE (2026-09-02)
- Model + data-author T1 items and Nettle. BC + ORM as painted. Neutral + Extended HoldPoses tested.
- In test level: pickup, Stone/Stick blunt swing, Sharpened Stone cuts TestTree and Nettle, Nettle WalkThrough + Fibrous Stalk yield.

A2. Ground crafting
- `UCraftingRecipeDefinition` + `UCraftingComponent` (recipe table, snapshot, session, one interpreter). Recipe owns `Stages`.
- Consume / spawn only through ItemFactory. R / player damage clears the session and leaves the bound items.
- Hands recipes first: Grind (`DA_Item_Stone`+`DA_Item_Stone` → `DA_Item_SharpenedStone`) then Twist (`DA_Item_PlantFiber`+`DA_Item_PlantFiber` → `DA_Item_Cordage`, presentation SKM).
- Strip after that PoC. Station / Tie / knap / forge / hone: later.

A3. Structure scaffolding + placed Workbench
- Structure Definition / Instance / Actor + fragment base.
- Workbench definition: station id + one slot.
- Slot uses the shared socket frame + item PlacementOffsetTransform.
- Place = Q + mouse hold (extend, preview snap) → release attach. Retrieve = same as ground pickup. Slot accepts a single item.
- Bench recipe: SharpenedStone + Stick + Cordage → StoneHatchet. One session, three minigame stages (Split / Seat / Wrap).

A4. Building + logs (final Core Loop stage)
- Player-built workbench from the ghost graph in Notes/StructureSystem/StructureSystemDefinition.txt (3 Log + 2 Cordage + 5 Stick).
- Two-handed log carry as needed for that build only.
- Shelter / degradation / decorative set: later.

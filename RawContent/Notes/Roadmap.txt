Woodcraft Survival – Project Roadmap
(Created 2026-08-26. Living document. High level only.)

Purpose
- This file is the high-level sequence of milestones. Look here when a task finishes and you need to choose the next slice.
- System implementation docs (ItemSystem/, HarvestableSystem/, CraftingSystem/, later StructureSystem/, CreatureSystem/) own locked architecture and small tasks for that system.
- ProjectNotes.txt owns the immediate working list only. Do not delete DONE lines from it without confirmation.

Core loop
Find loose resources → hold and swing a physical tool → harvest a standing resource into items → combine items into a better tool (hands, then a station) → harvest something the previous tool could not → repeat.

Food, fire, shelter, creatures, seasons, and the guidebook press on that loop. They are not the loop itself.

Current milestone: Core Loop Playable
A short session that starts nearly empty and completes gather → first ground craft → harvest → station craft → better harvest, using the live physics swing / incidence / orientation path.

In
- T1 item set as real data (stone / bone tech tier; there is no T0): Stone, Stick, SharpenedStone, PlantFiber, Cordage, StoneHatchet (dual-mesh: StickHandle Primary mesh + SharpenedStone Secondary). Handle is mesh-only — no Handle item DA. Copper Hatchet stays a T3 preview.
- Harvestables that feed the set: existing TestTree (sticks + stump), loose stones, Nettle (low HP, Slash only — Blunt and Pierce in Immunities, WalkThrough collision fragment). Yields Fibrous Stalk.
- Pickup / drop / extend / physics swing / incidence / orientation / damage + resistance (already live).
- Ground crafting: `DA_Item_Stone`+`DA_Item_Stone` → `DA_Item_SharpenedStone`; `DA_Item_PlantFiber`+`DA_Item_PlantFiber` → `DA_Item_Cordage`; then `DA_Item_FibrousStalk` + Unarmed → `DA_Item_PlantFiber`. Wood Scraps / Kindling wait for fire.
- Structure scaffolding (Definition / Instance / Actor + fragments), parallel to Items and Harvestables.
- Thin Workbench: one slot socket, placed in the test level first. Hatchet recipe is bench-only.
- StoneHatchet recipe: SharpenedStone + Stick + Cordage at Workbench.
- Building + two-handed log carry as the last stage of this milestone, after ground craft and the placed bench are proven. That is how the player obtains a bench in a real run.

Out of this milestone
- Stab impulse, throw, shoot.
- Part-break execution (designed in ItemSystemImplementation §10; StickHandle → BrokenStick / head detach is not Core Loop).
- Fire, cooking, food modes, spoilage, survival needs.
- Containers / stacking gameplay.
- Creature encounters (wolf weight paint is a parallel track).
- Flint knapping, forging, grindstone, leather, metals.

Art rule for this milestone
Readable color + authored ORM as assets are painted (pipeline locked: sRGB off, Masks). Shared Wood / Stone / Plant Physical Materials. Correct scale, named collision primitives, Neutral + Extended HoldPoses per item. No normal maps. Assembled hatchet may reuse `SM_SharpenedStone` with a second ORM / MI for wrap contact.

Locked decisions (2026-08-26)
- Item grip sockets are gone. Hold is HoldPose + item origin + dynamic grip (AnimRef Hand relative to WeaponBone × item world transform). Left-hand mesh scale X=-1 still applies.
- Station / placement sockets are allowed. Workbench has one slot socket.
- PlacementOffsetTransform lives on UItemDefinition (default Identity). Every station socket uses the same frame: origin on the surface, +Z up, +X forward. The item actor is placed at SocketTransform × PlacementOffsetTransform. Per-station special offsets are out until something actually needs them.
- Place onto a socket: Q + mouse hold extends the item (no swing) and preview-snaps; commit on RELEASE. Retrieve from a socket uses the same pickup path as a ground item. Held stacks never place onto sockets — Q + mouse release drops the whole stack.
- Cordage, Plant Fiber, Fibrous Stalk: Equippable, StrikeMode None, no Damage fragment. Fiber-source tag on the stalk only.
- Stick: Equippable, StrikeMode None, Damage fragment, blunt swing (no orient).
- Stone: Equippable, StrikeMode SingleEdged, Damage fragment, Blunt primitives (orient a flat; hits stay blunt).
- StoneHatchet Primary mesh is StickHandle (static mesh only), not a live Stick instance. Secondary is welded to Primary (`WeldTo`). Optional material overrides on the Definition.
- Recipes list allowed crafting locations (Hands / Ground and station ids). Station fragments carry a station id. Detection uses looked-at station or the item already in its slot. Recipe assets own the recipe list; stations do not duplicate it.
- Fragments stay data + spawn/init hooks on Structures, same as Items and Harvestables.
- Sharpened stone can cut trees and the fibrous plant. Stone hatchet is gated on the workbench.

Slices (do in order; each should be playable before the next starts)

A1. T1 content — DONE (2026-09-02)
- Model + data-author T1 items and Nettle. BC + ORM as painted. Neutral + Extended HoldPoses tested.
- In test level: pickup, Stone/Stick blunt swing, Sharpened Stone cuts TestTree and Nettle, Nettle WalkThrough + Fibrous Stalk yield.

A2. Ground crafting
- `UCraftingRecipeDefinition` + `UCraftingMinigameDefinition` + `UCraftingComponent` (recipe table, snapshot, session, one interpreter).
- Consume / spawn only through ItemFactory. R / player damage clears the session and leaves the bound items.
- Hands recipes first: Grind (`DA_Item_Stone`+`DA_Item_Stone` → `DA_Item_SharpenedStone`, `Physics`, LiveMeshes) then Twist (`DA_Item_PlantFiber`+`DA_Item_PlantFiber` → `DA_Item_Cordage`, `Guided`, presentation SKM).
- Strip after that PoC. Station / Tie / knap / forge / hone wait.

A3. Structure scaffolding + placed Workbench
- Structure Definition / Instance / Actor + fragment base.
- Workbench definition: station id + one slot.
- Slot uses the shared socket frame + item PlacementOffsetTransform.
- Place = Q + mouse hold (extend, no swing, preview snap) → release attach. Retrieve = same as ground pickup. Stacks cannot occupy the slot.
- Bench recipe: SharpenedStone + Stick + Cordage → StoneHatchet.

A4. Building + logs (final Core Loop stage)
- Player-built workbench from the ghost graph in Notes/StructureSystem/StructureSystemDefinition.txt (3 Log + 2 Cordage + 5 Stick).
- Two-handed log carry as needed for that build only.
- Still not the full shelter / degradation / decorative structure set.

After Core Loop Playable

C. Fire + one cook.
D. One living creature (wolf). Rig / weight paint can happen any time as a change of pace.
E. Needs + day cycle (stamina on swing/sprint, simple hunger, 24-min day).
F. Combat verbs that expand the loop rather than close it: stab, throw, two-hand weapons beyond logs.
G. Next progression tier (flint / leather), then copper.
